## 错因分类（统一用这些标签，方便统计）

- **词汇：** 不认识 / 认识但拼错 / 词形错（单复数、时态、词性）/ 搭配错
- **语法：** 语序 / 时态 / 从句 / 冠词 / 主谓一致
- **理解：** 定位错 / 推断过度 / 被干扰项带偏 / 没抓住转折
- **听力：** 没听清（连读弱读）/ 生词 / 记不住 / 语速跟不上
- **产出：** 要点遗漏 / 展开不足 / 无例子 / 语域不当 / 超时
- **发音：** 词尾辅音 / th / v-w / 重音 / 语调
