## 1. 收集信息

一次问完，不要一问一答地拖很多轮。用户已经给出的不要重复问。

1. **考试日期**：哪天考？（换算成剩余周数）
2. **目标分**：总分 + 单项最低要求。用户给的是学校要求（常是 0–120），用 `scripts/score_convert.py to-band` 换算总分、`section` 粗略换算单项要求。
3. **当前水平**：考过托福/雅思/多邻国/四六级吗？分数多少？没有就请用户自评或做快速诊断。
4. **时间投入**：工作日和周末每天大约多少小时？
5. **最弱项**：自己觉得哪个 section 最弱？有没有特别怕的题型？

缺信息时的默认假设（在计划中写明）：距考试 8 周、工作日每天 1.5 小时、周末每天 3 小时、目标总分 band 5（约 95–106）。

### 快速诊断（约 15 分钟）

用户没有任何成绩参考时提供：
- Reading：1 段 Complete the Words（10 空）+ 1 篇 Daily Life（2 题）
- Listening：5 道 Listen and Choose a Response（用文字稿 + 遮挡方式，见 listening.md）
- Writing：5 道 Build a Sentence + 1 封 7 分钟邮件
- Speaking：3 句 Listen and Repeat + 1 道 Interview 题（文字稿即可）

批改后给出每项的大致 band 区间，再出计划。

| 已有成绩 | 大致对应新版总分 band |
|---|---|

| 雅思 5.0 | 3 左右 |
| 雅思 5.5 | 3.5 左右 |

| 雅思 8.0+ | 5.5–6 |

## 3. 需要多少时间

经验估计（每天有效学习 1.5–2 小时）：

| 当前 → 目标 | 建议周数 |
|---|---|
| 提升 0.5 band | 4–6 周 |
| 提升 1 band | 8–12 周 |
| 提升 1.5 band 及以上 | 12–20 周，或分两次考 |
| 4.5 → 5.5 以上 | 高分段边际难度大，至少 10–12 周，且需要大量写作/口语反馈 |
| ≤ 3 起步 → 4–4.5 | 约 6–9 个月；前 2–3 个月以补基础为主 |

剩余时间明显不够时，坦白告诉用户，并给两个选项：(a) 调整目标或考两次（第一次摸底），(b) 压缩到最能提分的题型。不要假装时间够用。

## 4. 三阶段框架

按剩余周数分配：

| 阶段 | 占比 | 核心任务 |
|---|---|---|
| **基础期** | 约 40% | 词汇（会拼会用）、语法查漏、精听听写、跟读（shadowing）、熟悉全部新题型各做一遍 |
| **专项期** | 约 40% | 按题型刷原创练习，每周至少 2 篇写作 + 4 次口语批改；建立错题本，按错因专项突破 |
| **冲刺期** | 约 20% | 每周 1–2 次全真模考（自己计时）；只复盘错题本，不再开新资料；调整作息到考试时间 |

剩余不足 3 周时：跳过基础期，直接“题型熟悉 1 周 + 模考与复盘”。

**起点 band ≤ 3（基础薄弱）时：** 基础期延长到约 50%，内容加上音标/发音和系统语法（句子成分、时态、从句）；专项期先练短题型（Build a Sentence、Write an Email、Read in Daily Life、Listen and Choose a Response、Take an Interview），Academic Passage、Academic Talk、Academic Discussion 放到专项期后半段。每个阶段都设可检验的检查点，没达标就延长当前阶段，不要急着进入下一阶段。

## 5. 各 section 的提分优先级

性价比从高到低（一般情况，按诊断结果调整）：

1. **Writing – Build a Sentence**：规则明确、练得快，语法薄弱的考生 1–2 周就能明显提升。
2. **Writing – Write an Email**：格式固定（称呼、目的、3 要点、结尾），熟悉语域和常用句型后很快稳定。
3. **Reading – Complete the Words**：依赖词汇拼写，靠每天短时间积累；同时也带动写作准确度。
4. **Speaking – Take an Interview**：用“直接回答 → 理由 → 具体例子 → 收尾”的结构反复练 45 秒限时，提升稳定。
5. **Listening – Listen and Choose a Response**：需要语感和生活口语积累，靠大量短句听力。
6. **Speaking – Listen and Repeat**：依赖听力 + 短时记忆 + 发音，提升最慢，需要每天跟读。
7. **Academic Passage / Academic Talk**：词汇和背景知识的长期积累。

## 6. 每日/每周模板

### 工作日（约 1.5 小时）
| 时长 | 内容 |
|---|---|
| 20 分钟 | 词汇：新词 20 个 + 复习（间隔重复），重点练拼写 |
| 25 分钟 | 当天主攻 section 的专项练习（按周计划轮换） |
| 20 分钟 | 听力精听/听写 或 跟读（Listen and Repeat 训练） |
| 15 分钟 | 写作或口语产出 1 题（邮件/Interview 轮换），提交批改 |
| 10 分钟 | 整理错题本 |

### 周末（约 3 小时）
- 一个 section 的限时小模考 + 复盘
- 1 篇 Academic Discussion 限时写作 + 改写
- 本周错题本回顾，确定下周重点

### 轮换示例（专项期）
| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|---|---|---|---|---|---|---|
| Reading | Writing | Listening | Speaking | 最弱项 | 小模考 | 复盘 + 休息 |

## 7. 计划输出格式

```markdown
# 托福备考计划（考试日期：YYYY-MM-DD，剩余 N 周）

## 现状与目标
| | Reading | Listening | Speaking | Writing | 总分 |
|---|---|---|---|---|---|
| 当前（估计） | | | | | |
| 目标 | | | | | |
| 差距 | | | | | |
（假设：……）

## 策略要点
- 3 条以内，说明重点放在哪里、为什么

## 阶段安排
### 第 1–X 周：基础期
- 本阶段目标（可检验，例如“Build a Sentence 正确率 ≥ 80%”）
- 每周固定任务

### 第 X–Y 周：专项期
……

### 第 Y–N 周：冲刺期
……

## 一周样例
（表格，按天、按分钟）

## 检查点
- 第 X 周末：做一次诊断小测，达到 …… 则继续，否则 ……

## 今天就开始
- 给出今天可以立刻做的第一个练习（可以直接说“回复‘开始’我就出第一组题”）
```

计划要具体到“做什么、做多少、怎么算完成”，避免“多听多读”这种无法执行的建议。

## 8. 跟进与调整

用户回来汇报进度或贴出错题本时：
1. 对比检查点目标，指出哪项达标、哪项落后。
2. 落后的项先找错因（词汇？语法？时间？题型不熟？），再调整下一周配比。
3. 达标的项减少到“维持量”，时间挪给落后项。
4. 距离考试 2 周内不再改变大方向，只做查漏补缺和状态调整。
