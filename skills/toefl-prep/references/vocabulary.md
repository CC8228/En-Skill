## 1. 新版托福对词汇的要求

| 题型 | 需要的词汇能力 |
|---|---|
| Complete the Words | **拼写**准确 + 词形（复数、时态、词性） |
| Build a Sentence | 词性和搭配（动词后接什么、介词搭配） |
| Read in Daily Life / Conversation / Choose a Response | **校园生活词汇**和口语习语 |
| Academic Passage / Academic Talk | 学术话题词，常见词根词缀 |
| Email / Discussion / Interview | 能**主动使用**的准确词和搭配 |

结论：只认识中文意思不够，至少一半的新词要练到“会拼、会用一句话”。

## 2. 记忆方法

- **间隔重复：** 新词在第 1、2、4、7、15 天复习。用户没有工具时，建议用 Anki 或纸质卡片按日期分组。
- **词根词缀：** bio-（生命）、geo-（地）、-ology（学科）、trans-（穿过）、-ive/-ous（形容词）、-tion/-ment/-ity（名词）。看到生词先拆，Complete the Words 中也能用后缀猜剩余字母。
- **语境记忆：** 每个词配一个真实例句（最好来自做过的题），而不是孤立背中文。
- **主动输出：** 每天挑 5 个新词，在写作或口语练习里用出来。

## 3. 学术话题词表（起步版）

每个话题列高频词，出题和讲解时优先使用这些词。用户要扩充时，按话题原创例句生成更多。

**生物 / 生态：** organism, species, habitat, adapt / adaptation, predator, prey, evolve, reproduce, mutation, ecosystem, symbiosis, migrate, extinct, camouflage, nutrient

**地质 / 地理：** erosion, sediment, layer, crust, volcanic, glacier, mineral, fossil, plate, terrain, deposit, climate, drought, arid, landscape

**天文 / 物理：** orbit, gravity, planet, comet, atmosphere, radiation, telescope, galaxy, solar, particle, density, emit, collide, axis, eclipse

**考古 / 人类学：** artifact, excavate, settlement, ancestor, ritual, pottery, inscription, nomadic, agriculture, domesticate, civilization, tribe, migrate, prehistoric, remains

**艺术 / 建筑 / 文学：** sculpture, portrait, abstract, mural, architecture, facade, motif, genre, narrative, symbolism, aesthetic, medium, perspective, critic, exhibit

**心理 / 社会：** behavior, cognitive, perception, motivation, stimulus, conform, peer, bias, survey, participant, hypothesis, correlation, emotion, memory, social norm

**经济 / 商科：** demand, supply, consumer, revenue, profit, investment, inflation, labor, trade, market, competition, manufacture, retail, budget, incentive

**环境科学：** emission, renewable, pollution, conservation, sustainable, carbon, resource, biodiversity, deforestation, recycle, contaminate, habitat loss, mitigate, ecological, conserve

**历史：** empire, colony, revolution, merchant, dynasty, document, era, reform, territory, industrial, migration, decline, establish, treaty, archive

## 4. 校园生活词表

**选课 / 学业：** register, enroll, waitlist, prerequisite, syllabus, credit, transcript, major / minor, elective, drop / add a class, extension, office hours, teaching assistant (TA), midterm, GPA, academic advisor

**住宿 / 生活：** residence hall, dorm, roommate, resident assistant (RA), meal plan, maintenance request, lease, deposit, utilities, laundry, move-in / move-out

**设施 / 服务：** library card, check out (books), overdue, fine, study room, reservation, career center, health center, shuttle, parking permit, lost and found

**通知常用词：** mandatory, optional, eligible, deadline, no later than, prior to, waive, refundable, in advance, postpone, cancel, relocate, temporarily closed, effective immediately

**口语习语（Choose a Response 高频）：** I'm swamped. / It slipped my mind. / I'll pass. / Count me in. / Let's play it by ear. / That makes two of us. / I'm running late. / No wonder… / You can say that again. / I can't make it.

## 5. 写作与口语常用搭配

- 观点：I'm inclined to think… / I see where Kelly is coming from, but… / I'd argue that…
- 理由：The main reason is that… / This matters because… / What makes this important is…
- 举例：For instance, when I… / A good example is… / This happened to me last year when…
- 结果：As a result, … / This led to… / In the end, …
- 让步：Admittedly, … / That said, … / Even though…, I still think…
- 常用动词搭配：raise awareness, make progress, reach a decision, meet a deadline, take responsibility, gain experience, have an impact on, play a role in, cope with stress, keep up with

## 6. 在对话中运行一次词汇训练

用户说“背单词”“练词汇”时，默认流程（约 15 分钟）：

1. **问清范围：** 话题（或“随机”）+ 数量（默认 15 个）。
2. **学习：** 表格给出 单词｜词性｜中文｜英文例句（与托福场景相关）｜常见搭配。
3. **测验（下一条消息，不附答案）：** 混合三种题型
   - 看中文写英文（练拼写，对应 Complete the Words）
   - 补全字母：`env______ent`（environment）
   - 用词造句：选 2 个词各造一句
4. **批改：** 拼错的词单独列出，标注错误位置（如 enviroment 漏了 n），加入“明日复习”。
5. **结束：** 给出本次错词清单，提醒用户加入错题本或卡片。
