# 像素蛋糕（PixCake）面板对照

写方案时按这里的名称和顺序。面板清单来自像素蛋糕官方「色彩调节」说明：直方图、AI 校准、多图色彩统一、配置文件、滤镜、白平衡、影调、色阶、曲线、HSL、色彩编辑器、颜色分级、可选颜色、细节、颗粒、镜头调整、透视矫正、校准；另有局部调色（AI 识别主体/背景等区域）和人像、背景类 AI 精修工具。版本更新会改名或挪位置，用户找不到时，按“这个滑块管什么”描述让用户自己对上。

## 1. 推荐操作顺序

| 步骤 | 面板 | 目的 |
|---|---|---|
| 1 | 镜头调整、透视矫正 | 畸变、暗角、色差、歪斜，先把“底片”摆正 |
| 2 | AI 校准 或 白平衡 | 先回到准确的白平衡和曝光，再做风格 |
| 3 | 配置文件 / 滤镜（可选） | 用预设打底时在这一步套，后面再微调 |
| 4 | 影调 | 曝光 → 高光/阴影 → 白色/黑色 → 对比度，必要时清晰度、去雾、饱和度 |
| 5 | 曲线（或色阶） | 黑白点（哑光/压白）、S 曲线、单通道做色偏 |
| 6 | HSL / 色彩编辑器 / 可选颜色 | 控制每种颜色的色相、饱和、明度，决定“配色” |
| 7 | 颜色分级 | 阴影/中间调/高光分别上色，决定“氛围” |
| 8 | 校准 | 原色微调，做整体色彩质感（胶片、电影感常用） |
| 9 | 局部调色 | 主体提亮、背景压暗、天空单独处理 |
| 10 | 人像 / 背景精修 | 皮肤、五官、液化、去杂物、换天空 |
| 11 | 细节、颗粒、暗角 | 锐化、降噪、颗粒、暗角，最后加质感 |
| 12 | 多图色彩统一 / 同步 | 一组照片统一白平衡和亮度、同步参数 |

人像精修（第 10 步）和调色互不破坏，也可以先修人再调色；但肤色的最终判断放在调色之后。

## 2. 各面板管什么

| 面板 | 管什么 | 什么时候用 | 常见坑 |
|---|---|---|---|
| 直方图 | 亮度分布、溢出 | 全程看 | 只看直方图不看图；高调/低调作品本来就偏一边 |
| AI 校准 | 自动校正白平衡和曝光 | 原片偏色、曝光不准时打底 | 会把有意的氛围（暖色夕阳、冷色蓝调）校正掉，校完要看 |
| 多图色彩统一 | 以一张为基准统一一组照片的白平衡和亮度 | 组图、婚礼、旅拍 | 基准图要先修好 |
| 配置文件 | RAW 的基础色彩解释（类似 LR 的 Profile） | 想换基础色彩倾向时 | 换配置文件后前面的颜色判断要重看 |
| 滤镜 / 预设 | 一键风格 | 打底或给用户参考方向 | 强度通常要降，滤镜不能代替基础校正 |
| 白平衡 | 色温（蓝↔黄）、色调（绿↔洋红） | 每张都要看 | 肤色发绿/发紫多半是色调问题 |
| 影调 | 曝光、对比度、高光、阴影、白色、黑色等 | 每张都要调 | 阴影拉太多发灰、噪点；高光拉太多发脏 |
| 色阶 | 黑场/白场/中间调 | 和曲线二选一 | — |
| 曲线 | 亮度和对比的精细控制；RGB/红/绿/蓝单通道 | 哑光黑、压白、S 曲线、色偏 | 单通道动一点就很明显，起步要小 |
| HSL | 八种颜色各自的色相、饱和度、明亮度 | 定配色：压掉杂色、统一绿色、修肤色 | 动橙色会影响肤色，动完要看脸 |
| 色彩编辑器 | 更细的取色调整 | HSL 八色不够细时 | — |
| 颜色分级 | 阴影/中间调/高光（和全局）的色相与饱和 | 分离色调、青橙、胶片氛围 | 饱和度起步 5–15，太多会脏 |
| 可选颜色 | 按颜色调整 CMYK 成分（类似 PS 可选颜色） | 精细修某一颜色的成分 | — |
| 细节 | 锐化、降噪 | 输出前；高 ISO 先降噪 | 人像皮肤不要过度锐化 |
| 颗粒 | 胶片颗粒 | 胶片、港风、街拍 | 社交平台压缩会吃掉细颗粒，可以稍粗 |
| 镜头调整 | 畸变、暗角、色差 | 广角、大光圈 | 风格暗角在“效果/暗角”里加，不和镜头暗角校正混用 |
| 透视矫正 | 水平、垂直透视 | 建筑、室内 | 矫正后会裁边 |
| 校准 | 红/绿/蓝原色的色相与饱和 | 整体色彩质感 | 影响全图，幅度小 |

## 3. 滑块含义与常用幅度

按 −100 ~ +100 的常见刻度写；曝光单位是档（EV）；RAW 的色温通常显示为开尔文（K）。

| 滑块 | 作用 | 常用起步幅度 | 调到位的判断 |
|---|---|---|---|
| 色温 | 往右更暖黄，往左更冷蓝 | ±200–800K（非 RAW ±5–20） | 白色物体的颜色符合你想要的冷暖 |
| 色调 | 往右偏洋红，往左偏绿 | ±3–10 | 肤色不发绿、不发紫 |
| 曝光 | 整体亮度 | ±0.3–1.0 | 主体（通常是脸）亮度合适 |
| 对比度 | 亮的更亮、暗的更暗 | ±10–30 | 画面不灰也不硬 |
| 高光 | 只管亮部 | −20 ~ −60 | 天空、白衣服、额头出现层次 |
| 阴影 | 只管暗部 | +10 ~ +50 | 暗部细节可见但不发灰、不出噪点 |
| 白色 | 最亮端的位置 | ±5–25 | 最亮处接近但不溢出（按住滑块看溢出提示时以界面为准） |
| 黑色 | 最暗端的位置 | ±5–25 | 黑色扎实但不糊成一片 |
| 清晰度 | 中间调局部对比 | 风光/街拍 +10–25；人像 −5 ~ +5 | 质感出来但人脸不显脏 |
| 去雾（去朦胧） | 去掉灰雾、提对比和饱和 | +5–20 | 远景通透；负值做柔光雾感 |
| 自然饱和度 | 优先提低饱和颜色，保护肤色 | ±10–25 | — |
| 饱和度 | 所有颜色一起 | ±5–30 | 降饱和做高级灰时配合 HSL 留一两种主色 |
| 锐化 | 边缘锐度 | 适度；人像配合蒙版 | 放大 100% 看头发、睫毛 |
| 降噪 | 去亮度/色彩噪点 | 按 ISO：ISO 1600+ 开始需要 | 皮肤不变成塑料 |
| 颗粒 | 胶片颗粒 | 10–35 | 缩小到手机尺寸还看得出一点 |
| 暗角 | 四周压暗或提亮 | −10 ~ −30 | 不注意到暗角本身，但视线被引到中心 |

## 4. 曲线怎么写给用户

- 用 0–255 的“输入 → 输出”描述点位：例如“RGB 曲线：左下端点上抬到输出 20；在输入 64 处拉到 58，在输入 192 处拉到 200（轻 S）”。`compare_ref.py` 给的端点数值就是这个刻度。
- 常用写法：
  - **哑光黑（褪色感）**：左下端点上抬到 15–30。
  - **压白（柔和高光）**：右上端点下压到 235–245。
  - **轻 S 曲线**：输入 64 → 56–60，输入 192 → 198–204。
  - **阴影偏蓝/青**：蓝通道左下端点上抬 10–20（阴影加蓝）；**高光偏黄**：蓝通道右上端点下压 5–15。
  - **阴影偏绿（港风）**：绿通道左下端点上抬 5–15。
  - **整体偏暖红**：红通道中点轻微上提 3–5。
- 单通道每次只动一个点、幅度小，动完看中性色（白墙、灰路面）有没有跑偏。

## 5. 颜色分级的色轮角度

色轮角度（色相）大致对应：0° 红，30° 橙，50–60° 黄，120° 绿，180° 青，200–210° 天蓝/青蓝，240° 蓝，270° 紫，300° 洋红。`compare_ref.py` 和 `analyze_raw.py` 给出的“色轮方向”用的就是这套角度。

| 常见组合 | 阴影 | 高光 | 饱和度起步 |
|---|---|---|---|
| 青橙（电影感） | 190–210° | 35–45° | 阴影 15–30，高光 10–20 |
| 日系冷青 | 195–210° | 不加或 45° | 8–15 |
| 胶片暖 | 170–200°（轻） | 40–50° | 5–15 |
| 金色时刻 | 240–260° | 35–45° | 阴影 8–15，高光 15–25 |
| 港风 | 150–170° | 40–50° | 15–25 |
| 赛博夜景 | 220–240° | 300–320° | 10–25 |

“平衡”往负值偏让阴影色占比更大，往正值偏让高光色占比更大；“混合”越高两种颜色过渡越柔。界面里没有这两个滑块就忽略。

## 6. HSL 色相滑块的方向

八种颜色顺序：红 → 橙 → 黄 → 绿 → 青（浅绿/水绿）→ 蓝 → 紫 → 洋红（品红）→ 回到红。每个色相滑块：**往右（+）偏向顺序里的下一种颜色，往左（−）偏向上一种**。

| 颜色 | 往左（−） | 往右（+） | 常见用法 |
|---|---|---|---|
| 红 | 偏洋红 | 偏橙 | 嘴唇、红衣服；肤色偏红时 + |
| 橙 | 偏红 | 偏黄 | 肤色主控：− 更红润，+ 更黄 |
| 黄 | 偏橙 | 偏绿 | 树叶、草地的黄绿；− 让秋色更暖 |
| 绿 | 偏黄（橄榄、秋天） | 偏青（日系、清新） | 植物的“性格” |
| 青 | 偏绿 | 偏蓝 | 海水、玻璃 |
| 蓝 | 偏青 | 偏紫 | 天空：− 更青（电影感），+ 更深邃 |
| 紫 | 偏蓝 | 偏洋红 | 夜景灯光、花 |
| 洋红 | 偏紫 | 偏红 | 霓虹、花 |

`compare_ref.py` 的 HSL 建议已经换算成这个方向；它给的色相数值按“满格约 ±30°”估算，是起步值。

## 7. 校准（原色）

影响整张图的颜色解释，幅度一般在 ±10–40 之间，动完先看肤色。

- **蓝原色饱和度 +15 ~ +40**：整体颜色更浓郁、通透，胶片和电影感常用。
- **蓝原色色相 −10 ~ −40**：蓝色偏青、暖色更橙，青橙风的常用手法。
- **红原色色相**：+ 让肤色和红色偏橙黄，− 偏洋红、粉。
- **绿原色**：影响绿色和肤色的红绿平衡，小幅用，看肤色决定方向。

## 8. 局部调色、人像、背景

- **局部调色**：AI 识别主体/背景等区域生成蒙版，分别调影调和颜色。常用：主体曝光 +0.2 ~ +0.4、背景曝光 −0.3 ~ −0.6 或降饱和、天空降高光并调蓝色。头发、衣服可以单独修正。
- **人像（皮肤）**：磨皮、祛瑕疵、肤色统一、去黑眼圈/法令纹等。原则：先祛瑕疵，再中等强度磨皮（保留毛孔），肤色统一解决脸和脖子色差。
- **人像（五官 / 面部重塑、液化、美型）**：小幅，单项一般不超过 10–20 的强度；不要改变本人特征。
- **头发、服饰**：祛碎发、发色统一、头发光泽、衣服祛褶皱。
- **背景**：祛穿帮、祛路人、智能消除、换天空。RAW 层面高光已经溢出的大片天空，换天空比硬拉高光自然。

具体强度刻度因版本而异，方案里写“强度：轻/中”加判断标准即可。

## 9. Lightroom → 像素蛋糕 术语换算

| Lightroom / 英文 | 像素蛋糕 |
|---|---|
| Temp / Tint | 色温 / 色调 |
| Exposure, Contrast | 曝光、对比度 |
| Highlights, Shadows, Whites, Blacks | 高光、阴影、白色、黑色 |
| Texture, Clarity, Dehaze | 纹理、清晰度、去雾（去朦胧） |
| Vibrance, Saturation | 自然饱和度、饱和度 |
| Tone Curve（Point / Parametric，RGB/Red/Green/Blue） | 曲线（RGB / 红 / 绿 / 蓝） |
| HSL / Color Mixer（Hue/Saturation/Luminance） | HSL（色相 / 饱和度 / 明亮度） |
| Aqua | 青 / 浅绿 / 水绿 |
| Magenta | 洋红 / 品红 |
| Color Grading（Shadows/Midtones/Highlights/Global, Blending, Balance） | 颜色分级（阴影 / 中间调 / 高光 / 全局，混合，平衡） |
| Split Toning（旧版） | 颜色分级里的阴影和高光 |
| Calibration（Red/Green/Blue Primary） | 校准（红/绿/蓝原色） |
| Detail（Sharpening, Noise Reduction） | 细节（锐化、降噪） |
| Effects（Grain, Post-Crop Vignetting） | 颗粒、暗角 |
| Lens Corrections, Transform | 镜头调整、透视矫正 |
| Masking（Subject, Sky, Background） | 局部调色（AI 主体、背景、天空） |
| Profile | 配置文件 |
| Preset | 滤镜 / 预设 |

博主分享的 LR 预设参数可以按这张表直接搬，但同一数值在两个软件里的效果不完全一样，尤其是曲线和校准，搬过来后要按“判断标准”再看一遍。
