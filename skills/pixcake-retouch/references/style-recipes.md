# 常见风格配方（像素蛋糕）

每个风格给出：识别特征（用来判断参考图属于哪类）、适合的原片、按面板顺序的起步区间。区间是“从这里开始试”，最终以判断标准为准；有参考图时优先用 `compare_ref.py` 的结果，这里的区间用来核对方向和兜底。

数值约定：色温在 RAW 下写开尔文（K），其他滑块按 −100 ~ +100；曲线点按 0–255 的“输入 → 输出”；颜色分级角度见 `pixcake-panels.md` 第 5 节；HSL 色相方向见第 6 节。

## 1. 日系清新 / 空气感

**识别：** 高调或高短调；暗部通透不死黑；整体微冷或微青；绿色偏青且淡；肤色白里透粉；高光柔和。
**适合：** 阴天、树荫、窗光等柔光；光比小的照片。晴天硬光的照片要先大幅压高光、提阴影。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温 −200 ~ −500K 或保持中性；色调 +3 ~ +8（防止肤色发绿） |
| 影调 | 曝光 +0.3 ~ +0.8；对比度 −15 ~ −30；高光 −20 ~ −40；阴影 +30 ~ +50；白色 +10 ~ +20；黑色 +10 ~ +20；清晰度 −5 ~ −10 |
| 曲线 | 左下端点抬到 15–25；蓝通道左下抬 5–10（阴影微蓝） |
| HSL | 绿：色相 +15 ~ +30（偏青），饱和 −20 ~ −40，明亮度 +10 ~ +20；黄：色相 +10，饱和 −20；橙：饱和 −5 ~ −15，明亮度 +10 ~ +20；蓝：色相 −10，饱和 −10 ~ −20 |
| 颜色分级 | 阴影 200–210°，饱和 8–15；高光不加或 45° 饱和 5 |
| 质感 | 颗粒 0–10；人像磨皮轻到中 |

**判断：** 脸亮而不过曝、暗部看得见细节；画面里没有一块颜色特别跳。

## 2. 胶片感（Portra 暖调）

**识别：** 微暖；黑位微抬；高光柔、不刺眼；肤色暖橙但不红；绿色偏橄榄/偏黄；有颗粒。
**适合：** 日光人像、旅拍、生活记录；晴天和阴天都可。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温 +300 ~ +600K；色调 +3 ~ +5 |
| 影调 | 对比度 −10；高光 −30；阴影 +15；黑色 −5 ~ 0 |
| 曲线 | 左下端点抬到 15–30；右上端点压到 240–245；轻 S（64 → 58，192 → 198）；蓝通道右上压 5–10（高光偏黄） |
| HSL | 绿：色相 −15 ~ −25（偏黄），饱和 −20 ~ −35，明亮度 −10；橙：色相 −3 ~ +5，饱和 −5 ~ +5；蓝：色相 −10 ~ −15（偏青），饱和 −15 ~ −25；红：饱和 −5 ~ −10 |
| 颜色分级 | 阴影 170–200°，饱和 5–10；高光 40–50°，饱和 10–15 |
| 校准 | 蓝原色饱和 +15 ~ +30；红原色色相 +5 |
| 质感 | 颗粒 20–35，中等大小 |

**判断：** 白色像米白而不是纯白；绿色不再“荧光”；缩小看仍有颗粒感。

## 3. 电影感青橙

**识别：** 肤色和暖光偏橙，阴影和背景偏青蓝；对比中高；饱和集中在两种颜色上。
**适合：** 城市、街头、夜景人像、有暖光源的场景。

| 面板 | 调整 |
|---|---|
| 白平衡 | 中性或略冷 |
| 影调 | 对比度 +10 ~ +20；高光 −30；阴影 +10；黑色 −10；去雾 0 ~ +5 |
| 曲线 | 轻 S；左下端点抬 8–12（电影式的轻微灰黑） |
| HSL | 橙：饱和 +5 ~ +15；黄：色相 −10 ~ −20（偏橙），饱和 −20；绿：色相 +40 ~ +60（偏青），饱和 −40 ~ −60；青：饱和 +10；蓝：色相 −15 ~ −30（偏青），饱和 0 ~ +10；红：色相 +10（偏橙） |
| 颜色分级 | 阴影 190–210°，饱和 15–30；高光 35–45°，饱和 10–20；平衡 −10 ~ 0 |
| 校准 | 蓝原色色相 −20 ~ −40，饱和 +20 ~ +40 |
| 效果 | 暗角 −10 ~ −20 |

**判断：** 肤色健康不发红；背景的绿植不再是绿色而是偏青灰；画面里只有冷暖两组颜色。

## 4. 暗调情绪（Moody）

**识别：** 低调；阴影占大部分；黑位不完全死黑；饱和低；色调偏冷青或暖褐；主体靠局部光。
**适合：** 阴天、雨天、侧光/窗光人像、静物美食；不适合本来就很亮、光比很小的照片。

| 面板 | 调整 |
|---|---|
| 影调 | 曝光 −0.3 ~ −0.7；高光 −40 ~ −60；阴影 −10 ~ +10；黑色 −15 ~ −25；对比度 +5 ~ +15；清晰度 +5 ~ +15（人像少用）；自然饱和度 −10；饱和度 −10 ~ −25 |
| 曲线 | 先压黑，再把左下端点抬到 10–20（深但不死） |
| HSL | 绿：色相 −10（偏黄），饱和 −40 ~ −70，明亮度 −20 ~ −30；蓝：饱和 −30，明亮度 −20；橙：饱和 −10 |
| 颜色分级 | 冷：阴影 190–220°，饱和 10–20；暖褐：阴影 30–40°，饱和 10–15；高光 40°，饱和 5–10 |
| 局部调色 | 主体曝光 +0.3；背景曝光 −0.5 |
| 效果 | 暗角 −15 ~ −30 |

**判断：** 视线第一眼落在主体上；暗部虽暗但不是一块死黑；直方图左侧不贴边堆积。

## 5. 港风 / 王家卫

**识别：** 浓郁的红和绿；整体偏暖黄绿；暗部偏绿或青；对比强；颗粒重；常有霓虹。
**适合：** 街道、夜景、室内暖光、复古穿搭人像。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温 +300 ~ +800K；色调 −5 ~ −10（偏绿） |
| 影调 | 对比度 +20；高光 −20；阴影 −10；黑色 −10 |
| 曲线 | 绿通道左下抬 5–15（暗部偏绿）；蓝通道右上压 5–10（高光偏黄） |
| HSL | 红：饱和 +15，色相 −5；绿：色相 +10 ~ +20（偏青绿），饱和 +10；黄：色相 −10（偏橙）；橙：饱和 +5 |
| 颜色分级 | 阴影 150–170°，饱和 15–25；高光 40–50°，饱和 15 |
| 质感 | 颗粒 30–50；可以少量负清晰度做柔光 |

**判断：** 红色浓而不溢；肤色暖但不发绿（色调偏绿过头会让脸发青）。

## 6. 城市夜景 / 赛博

**识别：** 青和洋红为主；黑位干净；灯光不过曝；钠灯的橙黄被收掉或推向红/洋红。
**适合：** 霓虹街道、雨夜反光、城市天际线。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温 −500 ~ −1500K；色调 +5 ~ +15（偏洋红） |
| 影调 | 高光 −40 ~ −70（找回招牌细节）；阴影 +10 ~ +20；黑色 −10 ~ −20；对比度 +10；去雾 +5 ~ +15 |
| HSL | 橙：色相 −20 ~ −30（偏红）或饱和 −30 ~ −50；黄：饱和 −40 ~ −60；绿：色相 +40（偏青），饱和 −50；蓝：色相 −20（偏青），饱和 +15；紫：色相 +20（偏洋红）；洋红：饱和 +10 ~ +20 |
| 颜色分级 | 阴影 220–240°，饱和 15–25；高光 300–320°，饱和 10–15 |
| 细节 | 先降噪（夜景 ISO 高），再适度锐化 |

**判断：** 灯牌字能看清；暗部干净没有彩色噪点；整体只剩冷色和洋红两组颜色。

## 7. 冷调极简风光

**识别：** 低饱和；冷蓝；阴影抬起；远景通透；大面积留白或灰。
**适合：** 雪山、海、冰川、雾天、北欧冰岛类场景。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温 −300 ~ −800K；色调 0 ~ +5 |
| 影调 | 对比度 −5 ~ +10；高光 −30；阴影 +20；白色 +10；黑色 −10；去雾 +10 ~ +20；自然饱和度 −10 ~ −20 |
| 曲线 | 左下端点抬到 8–15 |
| HSL | 蓝：色相 −10 ~ −20（偏青），饱和 −10 ~ −30，明亮度 −10；青：饱和 −10；绿：色相 −10（偏黄，苔藓色），饱和 −40 ~ −60；橙、黄：饱和 −20 ~ −30 |
| 颜色分级 | 阴影 210–225°，饱和 10–20；高光 200°，饱和 0–5 |

**判断：** 雪是白偏一点冷而不是蓝；画面安静，没有高饱和的颜色。

## 8. 金色时刻暖调风光

**识别：** 金黄暖光；高光暖；阴影偏紫蓝（与暖光互补）；空气通透。
**适合：** 日出日落、逆光、侧逆光人像和风光。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温 +500 ~ +1200K；色调 +5 ~ +10 |
| 影调 | 高光 −40 ~ −60；阴影 +20 ~ +40；白色 +10；黑色 −10；对比度 +10；去雾 +5 ~ +15；自然饱和度 +10 ~ +20 |
| HSL | 橙：饱和 +10，明亮度 +5；黄：色相 −10 ~ −15（偏橙），饱和 +10；绿：色相 −15（偏黄），饱和 −20；蓝：色相 +10 ~ +15（偏紫），饱和 −10 |
| 颜色分级 | 高光 35–45°，饱和 15–25；阴影 240–260°，饱和 8–15 |
| 局部调色 | 天空曝光 −0.3 ~ −0.7（RAW 高光有余量时） |

**判断：** 太阳周围有层次而不是一块白；暗部不发脏的橙色。

## 9. 黑白

**识别：** 无色彩；要么高反差、颗粒重（街头），要么柔和细腻（人像）。
**做法：** 先把饱和度拉到 −100（或用黑白配置文件/滤镜），再用 HSL 明亮度控制各颜色转成的灰度。若拉 HSL 明亮度后画面没变化，改用黑白滤镜/配置文件里的颜色混合。

| 面板 | 街头高反差 | 柔和人像 |
|---|---|---|
| 影调 | 对比度 +20 ~ +40；清晰度 +10 ~ +25；黑色 −15；白色 +10 | 对比度 −10；高光 −20；阴影 +20 |
| HSL 明亮度 | 蓝 −20 ~ −40（天空压暗）；红、橙按主体决定 | 橙 +10 ~ +20、红 +5 ~ +10（肤色更亮更干净） |
| 颜色分级（可选） | 阴影 220° 饱和 5（冷黑） | 高光 40° 饱和 5（暖白） |
| 质感 | 颗粒 15–30；暗角 −10 ~ −20 | 颗粒 0–10 |

**判断：** 主体和背景在灰度上分得开；最暗和最亮处都有细节。

## 10. 韩系奶油 / 暖白

**识别：** 低对比；暖白、奶油黄；阴影微暖；饱和低；皮肤白净。
**适合：** 室内咖啡馆、窗光、白色或米色系穿搭。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温 +200 ~ +500K；色调 +3 ~ +5 |
| 影调 | 曝光 +0.3 ~ +0.5；对比度 −20 ~ −30；高光 −20；阴影 +20 ~ +30；白色 +5；黑色 +10 |
| 曲线 | 左下端点抬到 20–30；右上端点压到 245 |
| HSL | 黄：饱和 −20 ~ −30，明亮度 +10 ~ +20；橙：饱和 −10，明亮度 +10 ~ +20；绿：色相 −10（偏黄），饱和 −40；蓝：饱和 −30，明亮度 +10 |
| 颜色分级 | 高光 40–50°，饱和 8–15；阴影 30–40°，饱和 5–10 |

**判断：** 白墙是奶油色而不是黄色；肤色干净不蜡黄。

## 11. 人文街拍（彩色）

**识别：** 中高对比；局部对比明显；饱和偏低但颜色稳定；黑位扎实；常带颗粒。
**适合：** 街头、旅行人文、纪实。

| 面板 | 调整 |
|---|---|
| 影调 | 对比度 +15；高光 −20；阴影 +10；黑色 −15；清晰度 +10 ~ +20；自然饱和度 −10 |
| HSL | 保留画面里 1–2 个主色，其他颜色饱和 −20 ~ −40 |
| 效果 | 暗角 −10 ~ −20；颗粒 15–25 |

**判断：** 视线被光和主色引导；没有过度 HDR 的光晕和脏灰。

## 12. 胶片油润感

**识别：** 颜色“厚”——浓但不艳、不发荧光；肤色有一层自然光泽，过渡顺滑；高光柔和地滚落（不硬白）；暗部有颜色（暖褐或微青）而不是灰；绿色偏橄榄，红橙像油画颜料。常见于 Kodak Portra 160/400（略过曝）、Gold 200、Ektar 100 的中画幅作品。
**和第 2 节“胶片感（哑光）”的区别：** 哑光靠抬黑、降饱和做“淡”；油润靠压颜色明亮度、略提饱和做“密”，黑位只轻抬，所以颜色是沉下去的。
**适合：** 晴天侧光、逆光、金色时刻的人像；秋天落叶、暖色调场景尤其合适。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温 +300 ~ +600K；色调 +3 ~ +5 |
| 影调 | 曝光 +0.1 ~ +0.3；对比度 0 ~ +5；高光 −35 ~ −50（做出柔和的高光滚落）；阴影 +10 ~ +20；黑色 −5；清晰度 −5 ~ −10；纹理 −5；自然饱和度 +5 ~ +10 |
| 曲线 | 左下端点抬到 8–12（轻抬，保住密度）；右上端点压到 244–248；轻 S（64 → 58，192 → 198） |
| HSL | 橙：色相 −3 ~ −5，饱和 +5，明亮度 −5（肤色靠局部提亮补回）；黄：色相 −10（偏琥珀），饱和 +5，明亮度 −10 ~ −15；绿：色相 −20（偏橄榄），饱和 −15 ~ −25，明亮度 −15；蓝：色相 −5 ~ −10，饱和 −5，明亮度 −10；红：饱和 +5 |
| 颜色分级 | 中间调 35°，饱和 5–8（整体金色密度）；高光 45°，饱和 10–15；阴影 200° 饱和 5 或 30° 饱和 5（看想要冷还是暖的暗部） |
| 校准 | 蓝原色饱和 +20 ~ +30（油润感的关键之一）；红原色色相 +5，饱和 +5 ~ +10 |
| 局部调色 | 主体（人）曝光 +0.15 ~ +0.3，把被 HSL 压暗的肤色补回来 |
| 人像 | 磨皮轻；去油光只压最亮的热点，保留脸上自然的光泽——完全哑光就不“润”了 |
| 质感 | 颗粒 8–15，细颗粒 |

**判断：** 缩小看颜色浓而不躁，放大看皮肤细腻有光泽；落叶像油画颜料，不像荧光黄；暗部是“有颜色的暗”。

## 13. 欧式复古秋冬 lookbook（old money）

**识别（来自一组 15 张品牌秋冬 lookbook 的实测）：** 户外是低角度硬光阳光，人在光里、背景在阴影里，树几乎压成黑绿；黑位扎实（最暗约 10/255，不做哑光），白位收住（最亮约 210–220/255，米白大衣仍有纹理）；整体统一偏暖，阴影、中间调、高光都偏暖橙，中间调最暖，没有青橙分离；树叶和草被压成深橄榄金（HSV 色相约 53°、很暗），天空是浅青蓝（约 205°、饱和低）；鲜艳度中等（约 36），颜色集中在驼色、焦糖、酒红、奶油、牛仔蓝；肤色色相约 49°、彩度约 25，脸上亮部只到 L* 约 72，留一层光泽。
**适合：** 晴天低角度阳光的户外人像、木质室内窗光人像；服装是驼色、奶油、焦糖、酒红、藏青、牛仔这类色板时最出效果。
**光的结构（前期）：** 人和前景地面在阳光里，背景的树在阴影里（实测背景树 L* 约 6，阳光下的草 L* 约 50）。如果拍成“背景的树被阳光照亮、脚下地面在阴影里”，后期只能靠局部大幅压暗背景去接近，下次拍时换个角度，让背景落在阴影里。
**同类物体实测：** 阳光下的米色粗花呢 a* 约 +5、b* 约 +13.5（暖米色，不是黄米色）；牛仔是暗靛蓝、很低饱和（彩度 3–6，色相偏正蓝而不是青）；天空约 201–209°、饱和 30 左右。

| 面板 | 调整 |
|---|---|
| 白平衡 | 色温小调（0 ~ +300K），暖味主要交给颜色分级中间调 |
| 影调 | 高光 −40 ~ −60（压脸和浅色衣服的亮部）；白色 −10 ~ −20；黑色 −5；对比度 0 ~ +10；清晰度 +5（衣物纹理）；自然饱和度 −5 ~ −10 |
| 曲线 | 左下端点不抬或只抬到 6–8；右上端点压到 220–230；轻 S（64 → 58，192 → 196） |
| HSL | 黄：色相 −5，饱和 +10，明亮度 −30 ~ −40（亮黄树叶变深橄榄金）；绿：色相 −25，饱和 −10，明亮度 −30；橙：色相 −3，饱和 −5 ~ −10；红：饱和 +5；蓝：色相 −5，饱和 −10；青：饱和 −20 |
| 颜色分级 | 中间调 35–42°，饱和 12–15；阴影、高光不加反色 |
| 校准 | 红原色饱和 +10；蓝原色饱和 +15 |
| 局部调色 | 背景曝光 −0.4 ~ −0.7、高光 −40，把有阳光的杂乱背景压进阴影 |
| 人像 | 只压脸上最亮的点，保留光泽、雀斑和质感；磨皮轻 |
| 质感 | 细颗粒 10–15；不加暗角（背景本身够暗） |

**判断：** 缩小看，人是画面里最亮、最暖的地方，背景是深橄榄和暗棕；最暗处是实的黑棕，不发灰；奶油色衣服有纹理不死白。
**和第 12 节的区别：** 胶片油润感（日系）会轻抬黑位做柔和；这组 lookbook 黑位不抬、对比更足，“浓”来自深色背景和压住的高光。

## 通用提醒

- 同一个风格用在不同光线的照片上，幅度差别很大；硬光照片的高光、阴影通常要比柔光照片多动一倍。
- HSL 动了橙色、红色和黄色之后，一定回头看肤色。
- 先调对影调再调颜色：亮度变化会改变颜色的观感（压暗会让颜色显得更浓）。
- 组图先修一张基准图，再用“多图色彩统一”或同步参数，最后逐张微调曝光。
