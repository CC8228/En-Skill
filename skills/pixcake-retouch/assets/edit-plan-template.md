## 完成后自查

- [ ] 肤色正常（不发绿、不发紫、不蜡黄）
- [ ] 高光没有大片死白，暗部没有大片死黑（风格需要的除外）
- [ ] 白色物体的颜色符合目标冷暖
- [ ] 缩小到手机尺寸看，第一眼落在主体上
- [ ] 和参考图并排看，影调、配色、质感三项都接近

## 如果……就……

- 脸发灰 → 局部提亮主体，或减少阴影提亮、改用曲线中间调提亮
- 颜色发脏 → 先降对应颜色的饱和度，再检查颜色分级饱和是否过高
- 和参考比还是“不像” → 导出一张发给我，我用对比脚本找差距
